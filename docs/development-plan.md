## 验收标准（第一阶段）

1. 上传 PDF/DOCX/MD/TXT → 状态变为 ready（可查看状态、章节）
2. 知识库检索能溯源到文件名/章节/页码
3. 对话优先基于资料回答，无依据时明确提示
4. 自动总结包含核心知识点/重点概念/易错点/记忆内容/简短总结
5. 自动出题包含选择/判断/简答，带答案/解析/难度/知识点/章节
6. 错题自动入库，支持重新练习
7. 全部核心功能有自动化测试且通过
